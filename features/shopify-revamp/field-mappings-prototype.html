Field Mappings

Map Shopify fields to Refrens invoice fields. Required for GST-compliant invoices in India.
ℹ️
How this works. Shopify doesn't have native HSN or GSTIN fields. We read them from data Shopify already includes on the order webhook — line item properties, SKU patterns, tags, or note attributes. Pick the source for each field below, and we'll pull it into every Refrens invoice. If the source is empty for a given order, the default value is used.
Coming later: reading HSN/GSTIN from product, variant, or customer metafields (e.g. existing GST plugins). Not supported in v1.
