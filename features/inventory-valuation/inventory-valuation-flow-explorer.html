Valuation method change policy & FY lock

Changing an item's method

  • Locked within a financial year — no unbounded mid-year changes.
  • Schedule ahead during the current FY to take effect automatically at next FY start — zero recompute, the primary encouraged path.
  • Apply within a 7-day grace window from FY start — triggers a bounded recompute of that week's transactions only. Hard-blocked after day 7, no exceptions.
  • Not permanently locked for life — Ind AS 2 / IAS 2 permit a cost-formula change when applied consistently and disclosed.

FY lock

  • Previous-FY documents are read-only once locked — they can't be edited.
  • The current FY can still read prior-FY chain state (FIFO's surviving layers, or WAC's closing average) to carry forward — but can never modify it.

How the opening balance carries across the FY boundary

WACA single number — closing qty @ closing weighted-average cost.
FIFOA set of layers, each keeping its own original rate and date — not collapsed into one blended number.

Special cases resolved this session

Package / composite items
No independent ledger or valuation identity. A sale/purchase line explodes into one event per child item (package qty × child qty) — each hits that child's own chain and ledgers.
Warehouse transfers
No ledger entry in Phase 1 — Stock in Hand is a single global account, not per-warehouse. Still needs a chain-only tracking node (warehouse re-tag; FIFO layers may split) so per-warehouse reporting stays possible later.
Stock reconciliation
Same mechanics as Manual Adjustment IN/OUT. Direction is derived (counted vs expected qty), always no-party, and a count gain defaults to current average cost.
