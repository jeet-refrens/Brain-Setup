# kherpa-welcome-space

An AI-generated (Lovable.dev) Vite + React + shadcn/ui starter scaffold (package name `vite_react_shadcn_ts`). It's a generated baseline rather than a hand-built Refrens reference template.

**Tech:** Vite, React 18, shadcn/ui (Radix), TypeScript, Tailwind CSS, TanStack Query, React Hook Form + Zod, Lucide
**Tags:** frontend

## What it contains

- `src/components/` — UI components built with shadcn/ui primitives over Radix and Tailwind.
- `src/pages/` — application pages and high-level route layouts.
- `src/hooks/` — custom hooks for data fetching and state.
- `src/lib/` — utility libraries and configuration; `App.tsx` is the root component with routing.

## When to reach for it

- Working on the Kherpa welcome experience built on this scaffold.
- Reusing the generated Vite/React/shadcn/Tailwind stack as a starting point.
- Adjusting forms (Zod), routing, or data-fetching wired into the scaffold.
