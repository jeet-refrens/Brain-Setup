# gst-states

A static data package providing the official list of Indian states and union territories with their GST state codes, plus TypeScript types and lookup utilities.

**Tech:** JSON, JavaScript, TypeScript types
**Tags:** packages

## What it contains

- Complete list of 37 Indian states/UTs with their GST codes
- TypeScript type definitions
- Lookup utilities (code → name, name → code) and a `getAll()` accessor

## When to reach for it

- Updating or correcting Indian state / GST state-code reference data
- Adding lookup helpers or types for GST states consumed by forms or validation
- Verifying the canonical state list used in GST number formatting
