# jupiter

A higher-level React widget library built on top of the `disco` component library (`@refrens/jupiter` depends on `@refrens/disco`). It provides composed widgets and components, documented in Storybook.

**Tech:** React, TypeScript, Storybook, Formik (depends on `@refrens/disco`)
**Tags:** packages, frontend-web, full-stack

## What it contains

- Widgets and components under `src/components/`, built on top of `disco`.
- A Storybook (runs on port 9001) for developing and previewing the widgets.
- Form-oriented building blocks using Formik, Reflexbox, and Yup.

## When to reach for it

- Adding or changing a higher-level widget/component built on `disco`.
- Working on form-driven components (Formik/Yup) shared across web apps.
- Previewing or documenting widgets in Storybook.
