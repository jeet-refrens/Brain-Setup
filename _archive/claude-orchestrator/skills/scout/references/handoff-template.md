# Next Move Handoff Template

Use this structure for `NEXT_MOVE_HANDOFF.md` only when the dossier supports a
clear next move.

```markdown
# Next Move Handoff: <task name>

## Audience and source
- Intended implementer
- Scouting dossier
- Decision packet
- Related task / PRs

## TL;DR

## Goal

## Why this is the next move

## Decision journey - read this first
For each meaningful turn: question, decision, why, rejected alternatives, and
what must not be reintroduced.

## Locked decisions
| Decision | Rationale | Source |
|---|---|---|

## Current production behavior

## What already works - do not rebuild

## Required changes by repo / module

## Out of scope

## Acceptance criteria

## Verification checklist

## Rollout, migration, and observability

## Risks and pitfalls

## Open items to confirm during implementation

## References
```

Use real repo paths, ownership boundaries, contracts, and verification
commands. Do not turn unresolved product choices into implementation
instructions.
